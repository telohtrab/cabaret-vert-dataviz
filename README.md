# Cabaret Vert - A music festival artistic curation analysis

An archive and data visualization project around the artistic programming 
of the Cabaret Vert festival (2005–2025).

This is a personal training project to practice data visualization, data analysis and data processing tools.

## Status

🚧 Work in progress : currently building the dataset ; see sources below.

## Stack

- Python (data collection & enrichment)
- SQLite (database)

## Data Sources 

- Posters, flyers and running orders of 2009-2026 editions
- MusicBrainz API (artist metadata)
- Discogs API (artists genre and styles from releases / masters)
- Wikidata API (gender)
- Zicboom, POLCA zine
- archive.org : cabaretvert.com, associationflap.org
- Cabaret Vert social networks : Facebook, Twitter
- [reims-champagne-actu](https://www.reims-champagne-actu.com/dotclear/index.php?2008/08)
